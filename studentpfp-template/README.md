# Student profile picture template

`studentpfp-template.png` is the dedicated source artwork used for students without an uploaded profile picture. The optimized file served by the app is `public/images/studentpfp-template/studentpfp-template.webp`.

New students without an uploaded picture are assigned this template during account creation. Existing students without a usable photo display the same dedicated student template across the app. Staff profile presets remain separate.
