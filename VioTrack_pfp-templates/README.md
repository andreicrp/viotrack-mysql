# VioTrack profile picture templates

This folder contains the original PNG artwork for the profile picture templates shown on the Profile page.

The app serves optimized WebP copies from `public/images/viotrack-pfp-templates/` so selected profile pictures keep stable URLs after deployment. Keep the numbered filenames aligned between the source PNGs and the public WebP copies.

The five templates are the thinking, celebrating, heart, winking, and thumbs-up VioTrack mascots.
